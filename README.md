# Hi there, I'm Mehdi 👋
### Junior Web Application Security Tester

I am a passionate security enthusiast from Sargodha, Pakistan, focused on Web Application Penetration Testing and VAPT. I specialize in finding and validating OWASP Top 10 vulnerabilities through manual testing and hands-on lab environments.

---

## 🚀 What I Do
*   🔍 **Reconnaissance:** Mapping attack surfaces using Subfinder, httpx, and Katana.
*   🛡️ **Vulnerability Testing:** Manual testing for XSS, SQLi, IDOR, and Access Control flaws.
*   🔬 **Traffic Analysis:** Analyzing HTTP requests/responses using Burp Suite Professional.
*   📝 **Reporting:** Documenting findings with clear Proof of Concepts (PoC) and remediation steps.
